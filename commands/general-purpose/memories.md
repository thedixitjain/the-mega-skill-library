Read `.claude/memories/project_memory.json` and display:

```
# Project Memories

## Manual (user added)
- [content] (added X ago)

## Learned
- [type] content (added X ago)

Total: X memories
```

If empty: `📭 No memories yet. Use /remember [text] to add.`
