**None of the content in this repository is original work by the maintainer.**

`commands/`, `prompts/`, `rules/` and `reference/` was written by, and remains

publicly-available content from the 237 open-source repositories below so it
can be searched and used in one place. It is not a claim of authorship over
any harvested content.

## How attribution works here

- **Per-file**: every harvested file carries `source_repo`, `source_path` and
  `source_url` in its YAML frontmatter, plus a human-readable `Source:` footer
  linking straight back to the exact file in the exact upstream repo. Open any
  file in `library/`, `agents/`, `commands/`, `prompts/`, `rules/` or
  `reference/` and scroll to the top or bottom to see where it came from.
- **Per-repo**: the table below lists all 237 source repositories, linked
  directly to GitHub, with how many assets each one contributed. If you
  maintain one of these repos and want a correction, different attribution
  wording, or removal, please [open an issue](https://github.com/thedixitjain/the-mega-skill-library/issues) —
  requests from original authors are honored immediately.
- **Licensing**: this repository's own curation layer (the categorization,
  `CATALOG.tsv`, the router skill, and this documentation) is
  [MIT licensed](LICENSE). Every individual harvested file remains under its
  **original upstream repository's license** — check the linked source before
  redistributing or using a specific file commercially. See the source repo's
  own `LICENSE` file for the terms that actually apply to that content.
