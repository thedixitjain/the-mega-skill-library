# PUA P10

## 用途

- 当问题不是“怎么改”，而是“这件事到底值不值得做、要不要删、资源往哪打”时使用。

## 默认做法

1. 继承 [pua](../pua/SKILL.md) 的红线。
2. 先做减法，再谈优化和扩张。
3. 用第一性原理判断目标、约束、代价和替代方案。
4. 对低 ROI 的动作明确叫停，不把忙碌伪装成推进。
